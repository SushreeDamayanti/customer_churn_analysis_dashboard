
📊 Customer Churn Analysis Dashboard

📌 Project Overview

This project analyzes customer churn using Python and Power BI to identify customer behavior, understand churn patterns, and generate actionable business insights.

🎯 Business Objectives

- Analyze customer churn and retention.
- Identify subscription types associated with churn.
- Understand the relationship between payment delays and churn.
- Analyze customer spending patterns.
- Provide recommendations to improve customer retention.

🛠️ Tools & Technologies

- Python: Data analysis and exploration
- Pandas: Data manipulation
- Matplotlib & Seaborn: Data visualization
- Power BI: Interactive dashboard and business reporting
- Jupyter Notebook: Python analysis environment

📈 Dashboard Preview

"Customer Churn Dashboard" (customer_churn_dashboard.png.png)

📊 Key Analysis Areas

- Total Customers
- Churned Customers and Churn Rate
- Churn by Subscription Type
- Churn by Payment Delay
- Customer Spending Analysis

💡 Business Recommendations

- Investigate the reasons customers discontinue their subscriptions.
- Monitor customers who experience frequent payment delays.
- Compare churn rates across subscription types.
- Develop targeted customer retention strategies.
- Use customer spending patterns to support retention decisions.
